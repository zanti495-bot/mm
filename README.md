# Telegram Music Bot

Telegram-бот на Python и aiogram 3: ищет треки на YouTube и SoundCloud,
скачивает аудио через `yt-dlp` и отправляет его как Audio. Также можно
отправить прямую ссылку на сайт, поддерживаемый `yt-dlp`.

## Возможности

- Поиск по названию трека и исполнителю; бот сравнивает первые результаты
  YouTube и SoundCloud.
- Отправка MP3 как аудио с названием и исполнителем.
- Кнопки «Найти песню», «Помощь», «Источник» и «Найти ещё».
- Ограничения: трек не длиннее 20 минут, файл не больше 49 МиБ.
- FIFO-очередь запускает запросы по порядку: одновременно обрабатываются два,
  ещё до 50 могут ждать. Лимиты настраиваются в `music_bot/settings.py`.
- Аудио хранится во временной папке на диске только до отправки и затем удаляется;
  постоянный кэш скачанных треков не создаётся.
- Админ-панель со статистикой, экспортом базы пользователей в CSV,
  рассылкой и переключателем техработ.
- Рассылка копирует сообщение Telegram: сохраняются текст, форматирование,
  подпись и медиафайл. Перед отправкой показывается предпросмотр, требуется
  подтверждение и отображается прогресс доставки.
- Пользователи, заблокировавшие бота, автоматически исключаются из следующих
  рассылок.

## Структура проекта

```text
main.py                 запуск приложения
music_bot/
  settings.py           настройки из .env
  music.py              поиск и скачивание треков
  storage.py            SQLite, пользователи, статистика и настройки
  keyboards.py          клавиатуры пользователя и админ-панели
  handlers.py           обработчики Telegram-команд и сценариев
  download_queue.py     ограниченная очередь и параллельные worker'ы
tests/
  test_download_queue.py проверки очереди и параллельной обработки
requirements.txt        Python-зависимости
.env.example            шаблон переменных окружения
bot_data.sqlite3        локальная база, создаётся при первом запуске
```

`.env` и база данных исключены из Git. FSM рассылки и очередь запросов хранятся
в памяти: черновик рассылки сбрасывается при перезапуске, а при аварийном
завершении незаконченные запросы теряются. При штатном останове бот дожидается
обработки очереди. Временные аудиофайлы удаляются после отправки.

## Установка и запуск

### macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
brew install ffmpeg
```

Если `.env` ещё не создан, скопируй шаблон:

```bash
cp .env.example .env
```

Открой `.env` и укажи токен, полученный у [@BotFather](https://t.me/BotFather):

```dotenv
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=
```

Запусти бота из активированного виртуального окружения:

```bash
python main.py
```

При первом запуске `static-ffmpeg` проверит наличие `ffmpeg` и `ffprobe`. Если
их нет, пакет скачает совместимые бинарные файлы в окружение бота без прав
администратора. Для этого хостингу нужен доступ к интернету. На Ubuntu/Debian
можно вместо этого установить системный пакет командой `apt install ffmpeg`.

## Использование

1. Открой бота и отправь `/start`.
2. Нажми «🎵 Найти песню» или просто введи название песни и исполнителя.
3. После отправки аудио кнопка «Источник» откроет страницу трека, а
   «Найти ещё» начнёт новый поиск.

Кнопка «ℹ️ Помощь» показывает краткую инструкцию.

## Админ-панель

1. Отправь боту `/myid`, чтобы узнать свой Telegram ID.
2. Добавь ID в `.env`, например `ADMIN_IDS=123456789`. Несколько ID можно
   перечислить через запятую: `ADMIN_IDS=123456789,987654321`.
3. Перезапусти бота и отправь `/admin`.

В панели доступны статистика за текущие день, неделю и месяц, CSV-экспорт
пользователей и переключатель техработ. CSV отправляется администратору
файлом; в нём есть Telegram ID, имя, username, даты активности и состояние
доступности пользователя.

Для рассылки выбери «Создать рассылку», отправь боту одно сообщение и проверь
предпросмотр. Поддерживаются текст с форматированием и отдельные сообщения
с фото, видео, аудио или документом. Медиаальбомы не поддерживаются.
Рассылка отправляется пользователям из локальной базы, кроме заблокировавших
бота. Перед отправкой бот запрашивает подтверждение и показывает прогресс.

## Данные и конфиденциальность

База `bot_data.sqlite3` хранится рядом с `main.py`. В неё записываются Telegram
ID, имя, username, даты активности, состояние доступности и статусы поисковых
запросов. Текст поисковых запросов не сохраняется. Экспорт CSV
содержит персональные данные пользователей — не пересылай его посторонним.
